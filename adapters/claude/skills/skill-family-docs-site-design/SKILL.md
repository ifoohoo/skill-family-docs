# editorial 模板验收

`editorial` 是渲染包内的固定主题。项目通过页面清单和受限 Markdown 提供内容，不提供布局坐标、样式参数、脚本或自定义组件树。

## 固定阅读结构

- 桌面端使用约 240px 的左侧分组目录、680–740px 的主要正文和按需显示的右侧页内目录。
- 首页优先展示主要任务入口。任务页首屏给出用途和第一个可执行入口，完整字段和 CLI 参考放到参考页。
- 教程翻页由 `inPager` 页面的清单顺序派生。首页、参考页和排错页可以不进入教程；首页没有上一页，末页没有下一页。
- 正文默认不小于 16px，行高约 1.8。代码和表格在自己的容器内滚动，不撑宽页面。

## 交互验收

1. 左侧目录按 `pages.json` 分组，当前页可识别。窄屏改为可关闭面板，打开时不让背景滚动，关闭后恢复原位置和触发控件焦点。
2. 右侧目录来自稳定标题锚点。跳转后能重访同一章节，快速滚动后当前章节不滞后。
3. `prompt` 代码块显示“复制提示词”，普通代码显示“复制代码”。复制保留原文的首尾空白和换行，并给出成功或失败反馈。
4. 搜索只使用已公开的静态标题、章节和正文。标题优先，并列结果沿页面与章节顺序排列；中文短词、键盘选择和空结果都有可见反馈。
5. 搜索和移动目录可用 Escape 关闭并返回触发控件。所有交互控件有可见焦点和明确的可访问名称。
6. 浅色、深色和跟随系统都可读。正文对比度至少 4.5:1，大字至少 3:1；减少动态效果时禁用平滑滚动和非必要动画。
7. 移除增强脚本后，正文、直接链接、锚点和基础导航仍可使用。搜索、复制反馈和主题切换可以降级，不能让基础阅读失效。

## 视口与产物检查

至少在 1280×720、1440×900、390×844 和 320 CSS px 宽度下验收首页、长任务页、长表格和代码。同时检查浅色、深色、键盘路径、减少动态效果和无增强脚本样本。

交互操作不能改变生成文件。预览前后运行只读项目检查，若正式目录被宿主插桩，保留差异并停用该预览路径。

只有用户明确要求调整结构或升级模板时，才把发现的产品级差异交给 `skill-family-docs-render-site`。普通内容刷新不重新设计 UI。
