# 中文知识站拟稿与审校

起草、内容刷新或显式整篇重写时，由专用中文编辑子智能体通过 `agent-method-registry` 解析 `humanize-rewrite` 并执行返回的实现。通用表达方法由独立技能族维护。Docs 负责公开材料范围、页面身份、技术事实、图文与格式，以及 render-site 写回和覆盖。

只读审校可以定位事实、理解和表达问题，但不调用模型改稿，也不据此宣称拟稿流程已完成。

## 准备本站材料

读取 `references/writing.md`，看完本次文稿及直接事实来源。明确目标读者、允许的前置知识、阅读任务和最新用户裁决，整理完整原稿、核实后的背景事实、允许改写的范围及必须保留的机器值。

逐项核对页面 ID、URL、已有稳定锚点、代码、命令、版本和引用。不得把 quickstart 改成 setup 等不同入口。本地源版本不等于已发布或可安装版本；站点版本从 `public-release.json` 已声明的来源取得。

普通内容刷新保留 `pages.json` 的 ID、标题、分组、顺序、`productKind`、模板和输出路径。判断读者行为没有变化且原文仍符合目标时保留原文，并说明核对依据。命令全集放参考页，任务页在真正需要时才引入。

外发前移除不在公开材料范围的内容。该限制属于本站，不要求其他表达服务消费者照搬。首次向外部服务发送材料前说明发送目标，已有授权不逐次重复确认。凭据不进入文稿或上下文。

## 派发独立中文编辑者

读取 `agents/chinese-editor.md`，使用宿主原生子智能体工具创建 `docs_chinese_editor`。Codex 使用全新上下文（`fork_turns="none"`），只传该角色文件、项目根、完整原稿、核实材料、读者任务、编辑范围、用户裁决和新的候选输出位置，不继承整段对话。

编辑者负责查找已安装的 `humanize-rewrite` 入口，实际调用 Registry 解析方法，再执行所选 Skill 并核对候选。默认实现是 `chinese-humanize-rewrite`，用户可通过项目注册覆盖为 `shuorenhua` 或其他实现。没有子智能体工具、入口缺失、方法禁用、覆盖错误或候选未接受时，保留原稿并报告“表达优化未完成”，不得由主会话自行润色冒充该步骤。

环境检查与注册方式见 `references/expression-registry.md`。本技能不再内嵌通用模型调用脚本或复制写作方法。

## 核收并写回

读取 `references/revision.md` 与 `references/readability.md`。收到编辑者的完整候选、解析结果、实际执行方式、语义核对结果和未解决项后，主调用方对照原材料核对技术事实、条件、例外、限制强度、数字、代码、图表、引用和页面身份，通读全文并检查读者能否完成目标任务。必要时把集中意见交回同一编辑职责处理完整语义单元。

新格式的 Markdown 不写一级标题，页面 `title` 由 `pages.json` 生成。二至四级标题可在末尾声明 `{#id}` 稳定锚点；提示词使用 `prompt` 代码块，备注只用 `NOTE`、`TIP` 或 `WARNING`。正文不输入原始 HTML、MDX、样式或脚本。

编辑者接受不等于领域验收。完成核收后，由 render-site 的既有写路径把接受稿写入 `site.dir`，原稿与候选分开保留。不得提前刷新覆盖快照表示正文已审阅。

## 完成与失败边界

分别报告 Registry 解析、实际表达执行、编辑者接受与 Docs 领域核收状态。不得把安装成功、解析成功、模型调用成功或检测器通过当作全文通过。失败时报告具体原因与恢复入口。

纯渲染、`--check-project`、`--read-proof`、`--status`、`--refresh-coverage`、发布文档钩子、`check:release-docs`、setup、site-design、help、quickstart 自身及 `check-style.mjs` 均不向消费者的外部表达服务发起请求，也不通过这些操作修改文案。`npm run verify` 的自动测试不发起真实模型调用。quickstart 路由后的起草或刷新由目标技能执行上述编辑流程。

本次接入属于本地源码变更。是否已安装、已加载或已发布须分别核验，不从包版本号或目录存在推断。

## 辅助检测器

```bash
node scripts/check-style.mjs 稿件.md 页面.html
```

检测器只报告问题，不修改文件、不联网。Markdown 检查普通正文；旧 HTML 仅抽取 `<main>` 内文本，排除导航、页脚、样式、脚本与代码区。硬禁项退出 1，输入错误退出 2，其余退出 0。警告仅用于定位，修改仍由读者任务与事实决定。
