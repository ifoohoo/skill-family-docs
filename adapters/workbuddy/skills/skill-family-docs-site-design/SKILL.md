# 公开文档站视觉设计

文档站的设计目标只有一个：让人读得下去、找得到路。所有炫技都让位于这两条。

## 两种调用表面

- 自然语言输入：说明视觉目标或验收疑问；从项目文件读取站点源、页面范围和现有样式，只有范围、权限、安全边界或外部动作不明确时询问。
- 参数明确输入：直接给出站点源、页面范围以及设备和可访问性验收项；不再重复理解意图。

两种输入都汇合到本技能的版式、可访问性、样式约束与渲染后视觉验收流程。本技能是站点设计的唯一端到端业务入口，不增加 wrapper、controller、Worker、Registry、runner 或状态机。

## 一、版式

- **栏宽**：正文 `main` 最大宽度 800–880px，居中。中文行长控制在 35–45 字，栏太宽读者换行时找不到下一行。
- **行距**：正文 `line-height` 1.6–1.75；标题可以更紧。段间距用 margin 拉开，不靠空行。
- **导航层级**：渲染器生成的是平铺导航（`nav.toc`），视觉上就一层。页数有纪律（5–12 页），导航条目短于正文标题。当前页用 `a.active` 加粗或下划线标出，不只靠颜色区分。
- **翻页与页脚**：`nav.pager` 左右分置上一页 / 下一页，`footer.site` 放版权与许可。两者都用细边框与正文分隔，弱化处理（小字号、次要色）。
- **字体**：系统字体栈即可（`-apple-system, "Segoe UI", Roboto, …`），不引外部字体——公开站要快，也少一个外部依赖。

## 二、可读性与可访问性

- **对比度**：正文文字与背景对比度 ≥ 4.5:1（WCAG AA），次要文字（页脚、注释）≥ 3:1 且不承担关键信息。链接色与正文色要能一眼区分，且不只靠颜色—— hovered/focused 加下划线。
- **字号**：正文 ≥ 16px（`1rem`），导航和页脚可以降到 0.85–0.9rem，再小就不该承担信息。代码用等宽字体，行内 code 加浅底色和圆角即可。
- **键盘可达**：所有链接 Tab 可达且有可见 focus 样式（不要 `outline: none` 一删了之；要删就换成等效的自定义焦点环）。
- **动效**：文档站不需要动效。若加，尊重 `prefers-reduced-motion`。
- **深色模式**：用 CSS 变量定义前景 / 背景 / 强调色，`@media (prefers-color-scheme: dark)` 里换值。深色不是反色：背景别用纯黑（#0f0f14 一类），强调色要调亮保持对比度。

## 三、assets/style.css 定制约束

渲染器拷贝 assets 时走 allowlist：只有 `.html`、`.css`、`.js`、`.svg` 四种后缀会进产物，**png/jpg/woff 等二进制一律被跳过**。由此得到两条硬约束：

- **配图全部用自绘 SVG**：架构图、流程图直接写 SVG 文件放进站点源的 `docs/public/site/assets/`，或内联进 HTML。不引用任何位图。
- **不引外部资源**：CSS 里不要 `@import` 外部字体或 CDN，图片不指向站外 URL。公开站要可独立部署，外部依赖就是未来的死链。

其余约束：

- 样式集中在站点源的 `docs/public/site/assets/style.css` 一个文件，页面源只 `<link>` 它；不在每页写内联 `<style>`，避免视觉漂移。
- 用 CSS 变量管颜色，改主题只动 `:root`。
- 类名沿用渲染器注入的结构：`nav.toc`、`nav.pager`、`footer.site`、`a.active`——这几个是渲染器与样式之间的契约，改名字导航就裸奔。

## 四、渲染后视觉自检清单

渲染完成、浏览器打开产物后逐项过：

- **浅色 / 深色**：系统切换到两种模式各看一遍，正文、代码块、导航当前页、链接四种状态（普通 / 悬停 / 已访问 / 焦点）对比度都够。
- **窄屏**：窗口压到 360–400px 宽，导航换行不重叠、代码块横向滚动而不是撑破版心、翻页链接不挤在一起。
- **打印**：`Cmd/Ctrl+P` 预览，导航和页脚不挡正文（必要时 `@media print` 隐藏 `nav.toc`、`nav.pager`），链接不丢、页边距正常。
- **键盘**：纯 Tab 从地址栏走到页脚，每步焦点可见，顺序与视觉顺序一致。
- **内容完整性**：翻页链成环且逐页指向正确——链内末页的「下一页」回到链内首页，首页的「上一页」回到末页；SVG 图正常显示，无占位符残留，无 404 资源（开 DevTools Network 看一眼）。

清单全过后站点才算视觉交付完成；任一项不过，回 `docs/public/site/assets/style.css` 改源，不改产物。
